Thank you for visiting this page.

Fuyue is a unified program analysis framework for [Chisel](https://www.chisel-lang.org/), the most popular _modern_ hardware description language.
It is currently under active development and has not yet been publicly released.
Fuyue aims to bring together abstraction-based, search-based, and data-driven program analysis techniques under a shared infrastructure, providing a common foundation for exploring different approaches to analyzing hardware designs written in Chisel.

The ChiSA {% cite popl26chisa %} paper, along with its open-source artifact, represents an initial component of Fuyue.
These materials provide a glimpse into the project's early development state and preliminary capabilities prior to 2026.

I am continuing to improve Fuyue toward a mature release that supports broader usage and welcomes external contributions.
I look forward to sharing Fuyue with the community once it is ready. :)
